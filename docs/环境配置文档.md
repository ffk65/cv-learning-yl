| torchvision | *`0.15.2+cu118`* | 
| torchaudio | *`2.0.2+cu118`* |
| NumPy | *`1.26.4`* | 

安装命令:
```
pip install torch==2.0.1 torchvision==0.15.2 torchaudio==2.0.2 --index-url https://download.pytorch.org/whl/cu118
```

**可用性验证（实测通过）**：`torch.cuda.is_available()` → `True`；`torch.cuda.get_device_name(0)` → `NVIDIA GeForce RTX 3060 Laptop GPU`。
**版本配套注意**：`torch 2.0.1` 按 NumPy 1.x 编译，NumPy 必须 `<2`（已装 `1.26.4`）；否则导入时报 `Failed to initialize NumPy: _ARRAY_API not found`。
