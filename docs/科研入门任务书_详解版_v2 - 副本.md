### 步骤 4｜模型（1）：backbone + neck

> **本步目的**：把"图 → C3/C4/C5 → P3/P4/P5 → 每位置 9×(20+4) 预测 → 18900 anchors"这条前向链跑通（**不训练**）。
> **调用关系**：`config/config.py` → `Backbone.forward` → `FPN.forward` → `Head.forward` → `generate_anchors`，全部由 `RetinaNet.forward` 串起来。
> **验收**：`python -m models.retinanet` 打印三层 shape + `(18900,4)`（见步骤 7 末）。

#### 4.1 结构总览

1. **backbone 只负责"提特征"**：ResNet-18 的 `layer2/layer3/layer4` 分别给你 stride 8/16/32 的三张特征图（C3/C4/C5）。
2. **FPN 只负责"融合"**：深层上来 + 浅层相加，让每层都既有语义又有分辨率。
3. **head 只负责"出预测"**：每个位置出 `9×(20+4)` 个数 = 9 个 anchor，每个 anchor 20 个类别分数 + 4 个框偏移。

#### 4.2 写 `backbone.py` 和 `neck.py`

> **为什么拆**：mmdetection 把骨干放在 `models/backbones/`、颈部放在 `models/necks/`，detectron2 也是 `backbone/resnet.py` + `backbone/fpn.py` 分开。拆开后汇报时能明确说"我只改了 neck 的通道数"，也方便单独替换。

```python
# 文件：models/backbone.py
# 核心作用：ResNet-18 只提取 C3/C4/C5（对应 mmdet 的 models/backbones/resnet.py）
# 调用关系：models/neck.py 的 FPN.forward 接收本类输出；models/retinanet.py 的 RetinaNet.forward 先调本类
import torch.nn as nn                                # 网络层
from torchvision.models import resnet18, ResNet18_Weights   # 官方 ResNet-18 + 预训练权重


class Backbone(nn.Module):
    """功能：骨干网络，输出 stride 8/16/32 的三层特征
    输入：x (B,3,H,W)，H/W 建议 320
    输出：[C3(B,128,H/8,W/8), C4(B,256,H/16,W/16), C5(B,512,H/32,W/32)]
    调用位置：RetinaNet.forward()（models/retinanet.py）第一行
    """

    def __init__(self, pretrained=True):
        super().__init__()                            # 初始化 nn.Module
        # 预训练权重能显著加快收敛；没有网络时会自动下载到 ~/.cache/torch
        weights = ResNet18_Weights.DEFAULT if pretrained else None
        rn = resnet18(weights=weights)                # 官方实现，输出 1000 类（我们不用它的 fc）
        # 按 stride 拆开：stem=/4，layer1=/4，layer2=/8，layer3=/16，layer4=/32
        self.stem = nn.Sequential(rn.conv1, rn.bn1, rn.relu, rn.maxpool)
        self.layer1 = rn.layer1                       # 输出 (B, 64, 80, 80)
        self.layer2 = rn.layer2                       # 输出 (B,128, 40, 40) → C3
        self.layer3 = rn.layer3                       # 输出 (B,256, 20, 20) → C4
        self.layer4 = rn.layer4                       # 输出 (B,512, 10, 10) → C5

    def forward(self, x):
        """功能：一次前向，返回 C3/C4/C5
        输入：x (B,3,H,W)
        输出：[C3, C4, C5]
        调用位置：RetinaNet.forward()；neck.FPN.forward()
        """
        c2 = self.stem(x)                             # (B, 64, 80, 80)
        c3 = self.layer2(self.layer1(c2))             # (B,128, 40, 40)
        c4 = self.layer3(c3)                          # (B,256, 20, 20)
        c5 = self.layer4(c4)                          # (B,512, 10, 10)
        return [c3, c4, c5]
```

```python
# 文件：models/neck.py
# 核心作用：FPN 把 C3/C4/C5 融合成 P3/P4/P5（对应 mmdet 的 models/necks/fpn.py）
# 调用关系：RetinaNet.__init__ 创建本类；RetinaNet.forward 把 backbone 的输出喂给本类
import torch.nn.functional as F                      # 用于最近邻上采样
import torch.nn as nn                                # 网络层
from config.config import fpn_channels              # 统一通道数 256


class FPN(nn.Module):
    """功能：自顶向下 + 横向连接，输出三层 256 通道特征
    输入：feats = [C3, C4, C5]（来自 Backbone）
    输出：[P3(B,256,40,40), P4(B,256,20,20), P5(B,256,10,10)]
    调用位置：RetinaNet.forward()（models/retinanet.py）
    """

    def __init__(self, in_channels=(128, 256, 512), out_channels=fpn_channels):
        super().__init__()                            # 初始化 nn.Module
        c = out_channels                              # 简写，256
        self.lat3 = nn.Conv2d(in_channels[0], c, kernel_size=1)  # 横向 1×1：C3 128→256
        self.lat4 = nn.Conv2d(in_channels[1], c, kernel_size=1)  # 横向 1×1：C4 256→256
        self.lat5 = nn.Conv2d(in_channels[2], c, kernel_size=1)  # 横向 1×1：C5 512→256
        # 融合后再过 3×3，消除上采样带来的"网格感"（对应 6.8 FPN 的输出卷积）
        self.out3 = nn.Conv2d(c, c, kernel_size=3, padding=1)
        self.out4 = nn.Conv2d(c, c, kernel_size=3, padding=1)
        self.out5 = nn.Conv2d(c, c, kernel_size=3, padding=1)

    def forward(self, feats):
        """功能：自顶向下融合，返回三层特征
        输入：feats=[C3,C4,C5]
        输出：[P3,P4,P5]
        调用位置：RetinaNet.forward()（models/retinanet.py）
        """
        c3, c4, c5 = feats
        p5 = self.lat5(c5)                            # 顶层直接用横向卷积
        p4 = self.lat4(c4) + F.interpolate(p5, size=c4.shape[-2:], mode="nearest")  # 上采样后逐元素相加
        p3 = self.lat3(c3) + F.interpolate(p4, size=c3.shape[-2:], mode="nearest")  # 与 p4 相同的自顶向下融合
        return [self.out3(p3), self.out4(p4), self.out5(p5)]   # 3×3 平滑后输出
```

> **本步可改**：`pretrained` 改 False 就是从零训练（12 epoch 基本学不出来）；`fpn_channels` 128 省显存但精度降、512 在 6GB 上容易 OOM；backbone 可换 resnet34/50（更慢、更吃显存）；`anchor_scales` 改小目标加 16、大目标加 256，**必须同步步骤 5/6 的数量**。

### 步骤 5｜模型（2）：anchor 生成 / 编码 / 解码

> **本步目的**：生成 18900 个 anchor，并提供 GT→偏移（encode）和预测→框（decode）两个变换。
> **调用关系**：`RetinaNet.forward` 调 `generate_anchors`；`Loss.forward` 调 `encode`；`trainer/eval.py`、`tools/predict.py` 调 `decode`。
> **验收**：`python -c "from models.anchor import generate_anchors; print(generate_anchors([(40,40),(20,20),(10,10)],'cpu').shape)"` → `(18900, 4)`。

```python
# 文件：models/anchor.py
# 核心作用：① 为 P3/P4/P5 生成 anchor；② 把 GT 编码成回归目标；③ 把预测解码成真实框
# 调用关系：RetinaNet.forward → generate_anchors；losses/loss.py → encode；trainer/eval.py、tools/predict.py → decode
import math                                          # sqrt
import torch                                         # 张量
from config.config import anchor_scales, anchor_ratios, anchor_strides   # 尺度/比例/步长


def generate_anchors(feature_sizes, device):
    """功能：生成所有 anchor（xyxy 绝对坐标）
    输入：feature_sizes=[(40,40),(20,20),(10,10)]（P3/P4/P5 的高宽）；device
    输出：(18900, 4) float32 —— 顺序 = 层 → 位置(h,w) → 尺度 → 比例
    调用位置：RetinaNet.forward()（models/retinanet.py）
    """
    anchors = []                                     # 用 Python list 收集，最后一次性转张量
    for (fh, fw), stride in zip(feature_sizes, anchor_strides):   # 逐层
        for i in range(fh):                          # 行（y 方向）
            for j in range(fw):                      # 列（x 方向）
                cx = (j + 0.5) * stride              # 该位置对应原图的中心 x
                cy = (i + 0.5) * stride              # 该位置对应原图的中心 y
                for s in anchor_scales:              # 3 种尺度
                    for r in anchor_ratios:          # 3 种比例 → 每位置 9 个
                        h = s / math.sqrt(r)         # 由"面积≈s² + 比例"反推高
                        w = s * math.sqrt(r)         # 反推宽
                        anchors.append([cx - w / 2, cy - h / 2, cx + w / 2, cy + h / 2])
    return torch.tensor(anchors, dtype=torch.float32, device=device)


def encode(anchors, gt):
    """功能：把"anchor → GT"的偏移编码成回归目标（RetinaNet 的 4 参数形式）
    输入：anchors (N,4) xyxy；gt (N,4) xyxy（长度必须相同，已一一配对）
    输出：(N,4) = [dx, dy, dw, dh]
    调用位置：losses/loss.py 的 assign_targets()
    """
    aw = anchors[:, 2] - anchors[:, 0]               # anchor 宽
    ah = anchors[:, 3] - anchors[:, 1]               # anchor 高
    acx = anchors[:, 0] + 0.5 * aw                   # anchor 中心 x
    acy = anchors[:, 1] + 0.5 * ah                   # anchor 中心 y
    gw = gt[:, 2] - gt[:, 0]                         # GT 宽
    gh = gt[:, 3] - gt[:, 1]                         # GT 高
    gcx = gt[:, 0] + 0.5 * gw                        # GT 中心 x
    gcy = gt[:, 1] + 0.5 * gh                        # GT 中心 y
    dx = (gcx - acx) / aw                            # 中心偏移（归一化）
    dy = (gcy - acy) / ah
    dw = torch.log(gw / aw)                          # 宽比取 log（保证恒正）
    dh = torch.log(gh / ah)
    return torch.stack([dx, dy, dw, dh], dim=1)      # (N,4)


def decode(anchors, deltas):
    """功能：把网络输出的偏移还原成真实框（encode 的逆运算）
    输入：anchors (N,4) xyxy；deltas (N,4) = [dx,dy,dw,dh]
    输出：(N,4) xyxy
    调用位置：trainer/eval.py 的 postprocess()；tools/predict.py
    """
    aw = anchors[:, 2] - anchors[:, 0]               # anchor 宽
    ah = anchors[:, 3] - anchors[:, 1]               # anchor 高
    acx = anchors[:, 0] + 0.5 * aw                   # anchor 中心
    acy = anchors[:, 1] + 0.5 * ah
    gcx = deltas[:, 0] * aw + acx                    # 还原中心 x
    gcy = deltas[:, 1] * ah + acy                    # 还原中心 y
    gw = torch.exp(deltas[:, 2]) * aw                # 还原宽
    gh = torch.exp(deltas[:, 3]) * ah                # 还原高
    return torch.stack([gcx - gw / 2, gcy - gh / 2, gcx + gw / 2, gcy + gh / 2], dim=1)
```

> **本步可改**：`anchor_scales` / `anchor_ratios` 决定 anchor 大小与形状，数量变了必须同步步骤 6 的 `num_anchors` 与损失；`anchor_strides` 必须与 P3/P4/P5 分辨率一致，**不要单独改**。

### 步骤 6｜模型（3）：head

> **本步目的**：把每层特征变成 `9×(20+4)` 个预测，输出 cls/reg 两个列表。
> **调用关系**：`RetinaNet.forward` 对 P3/P4/P5 逐层调用 `Head.forward`，结果交给 `flatten_outputs` 和 `Loss`。
> **验收**：`python -m models.retinanet` 中 cls 通道 180、reg 通道 36（见步骤 7）。

> **为什么拆**：mmdetection 的 `Head` 在 `models/dense_heads/`，整机 `RetinaNet` 在 `models/detectors/`；detectron2 则把两者都放进 `meta_arch/retinanet.py`。我们选 mmdet 的拆法，汇报时层次更清楚。

```python
# 文件：models/head.py
# 核心作用：RetinaNet 的检测头（分类塔 + 回归塔，各层共享权重）
# 调用关系：models/retinanet.py 的 RetinaNet.__init__ 创建本类；RetinaNet.forward 调用本类
import math                                          # log
import torch.nn as nn                                # 层
from config.config import num_classes, anchor_scales, anchor_ratios, fpn_channels   # 常量


class Head(nn.Module):
    """功能：RetinaNet 的检测头（各层共享权重）
    输入：feats = [P3,P4,P5]（每个 256 通道）
    输出：cls_list = [ (B,9×20,H,W) ×3 ]；reg_list = [ (B,9×4,H,W) ×3 ]
    调用位置：RetinaNet.forward()
    """

    def __init__(self, num_classes=num_classes, num_anchors=None, ch=fpn_channels):
        super().__init__()                            # 初始化
        num_anchors = num_anchors or len(anchor_scales) * len(anchor_ratios)   # 9
        # 分类塔：两层 3×3（原文是 4 层，这里减半，6GB 更快）
        self.cls_tower = nn.Sequential(
            nn.Conv2d(ch, ch, 3, padding=1), nn.ReLU(inplace=True),
            nn.Conv2d(ch, ch, 3, padding=1), nn.ReLU(inplace=True),
        )
        # 回归塔：结构独立（原文就是分类/回归分开，不共享）
        self.reg_tower = nn.Sequential(
            nn.Conv2d(ch, ch, 3, padding=1), nn.ReLU(inplace=True),
            nn.Conv2d(ch, ch, 3, padding=1), nn.ReLU(inplace=True),
        )
        self.cls_logits = nn.Conv2d(ch, num_anchors * num_classes, 1)   # 1×1 → 每位置 180 个分数
        self.bbox_pred = nn.Conv2d(ch, num_anchors * 4, 1)              # 1×1 → 每位置 36 个偏移

        for m in self.modules():                       # 初始化（RetinaNet 原文做法）
            if isinstance(m, nn.Conv2d):
                nn.init.normal_(m.weight, std=0.01)    # 小方差，训练初期稳定
                nn.init.constant_(m.bias, 0)
        # 关键：分类 bias 初始化为 -log((1-0.01)/0.01)≈-4.595
        # 目的：初始时每个 anchor 的正类概率≈0.01，避免一上来就被大量负样本主导
        nn.init.constant_(self.cls_logits.bias, -math.log((1 - 0.01) / 0.01))

    def forward(self, feats):
        """功能：逐层出分类/回归预测
        输入：feats = [P3,P4,P5]
        输出：cls_list、reg_list（见类注释）
        调用位置：RetinaNet.forward()
        """
        cls_outs, reg_outs = [], []                    # 收集三层结果
        for f in feats:                                # 逐层（权重共享）
            cls_outs.append(self.cls_logits(self.cls_tower(f)))   # 分类
            reg_outs.append(self.bbox_pred(self.reg_tower(f)))    # 回归
        return cls_outs, reg_outs
```

> **本步可改**：`num_classes` 换数据集必须改（同时改 config 和 Dataset 类别表）；`num_anchors` 由 anchor 配置决定，改一处要全链路同步；分类 bias 初始化 `-4.595` 不要删，删了前期 loss 会爆炸。

> **本步目的**：把 backbone / neck / head / anchor 串成整机，并验证所有 shape 对齐。
> **调用关系**：`RetinaNet.forward` → Backbone → FPN → Head → `generate_anchors`；`flatten_outputs` 供 Loss 使用。

```python
# 文件：models/retinanet.py
# 核心作用：把 backbone / neck / head 组装成整机；提供 forward 与"逐层结果展平"工具
# 运行自检：python -m models.retinanet
# 调用关系：trainer/train.py、trainer/eval.py、tools/predict.py 都 import RetinaNet
import torch                                         # 张量
import torch.nn as nn                                # 层
from models.backbone import Backbone         # 骨干（models/backbone.py）
from models.neck import FPN                          # 颈部（models/neck.py）
from models.head import Head                   # 检测头（models/head.py）
from models.anchor import generate_anchors           # anchor 生成（models/anchor.py）
from config.config import num_classes                # 类别数


class RetinaNet(nn.Module):
    """功能：整机 = backbone + neck + head + anchor
    输入：x (B,3,H,W)
    输出：(cls_list, reg_list, anchors)
    调用位置：trainer/train.py 训练循环；trainer/eval.py；tools/predict.py
    """

    def __init__(self, pretrained=True):
        super().__init__()                            # 初始化
        self.backbone = Backbone(pretrained)  # models/backbone.py
        self.neck = FPN()                             # models/neck.py
        self.head = Head()                      # models/head.py

    def forward(self, x):
        """功能：一次前向
        输入：x (B,3,320,320)
        输出：cls_list (3 个 (B,180,H,W))、reg_list (3 个 (B,36,H,W))、anchors (18900,4)
        调用位置：trainer/train.py 的 train_one_epoch()；trainer/eval.py
        """
        c3, c4, c5 = self.backbone(x)                                  # 骨干输出 C3/C4/C5
        feats = self.neck([c3, c4, c5])                                # FPN → (P3,P4,P5)
        cls_list, reg_list = self.head(feats)                           # 逐层预测
        sizes = [(c.shape[-2], c.shape[-1]) for c in cls_list]          # 各层高宽
        anchors = generate_anchors(sizes, x.device)                     # 18900 个 anchor
        return cls_list, reg_list, anchors


def flatten_outputs(cls_list, reg_list):
    """功能：把逐层输出拼成"每张图一条长表"，与 anchors 顺序一一对应
    输入：cls_list=[(B,A*C,H,W)×3]、reg_list=[(B,A*4,H,W)×3]
    输出：cls (B, N, C)、reg (B, N, 4)，N = Σ(H×W×A) = 18900
    调用位置：losses/loss.py 的 Loss.forward()；trainer/eval.py
    """
    cls_flat, reg_flat = [], []                       # 收集展平后的层
    for c, r in zip(cls_list, reg_list):
        b, ac, h, w = c.shape                         # 分类通道 = A*C
        a = ac // num_classes                         # 反推 anchor 数（9）
        # (B,A*C,H,W) → (B,A,C,H,W) → (B,H,W,A,C) → (B,H*W*A,C)
        cls_flat.append(c.view(b, a, num_classes, h, w).permute(0, 3, 4, 1, 2).reshape(b, -1, num_classes))
        # (B,A*4,H,W) → (B,A,4,H,W) → (B,H,W,A,4) → (B,H*W*A,4)
        reg_flat.append(r.view(b, a, 4, h, w).permute(0, 3, 4, 1, 2).reshape(b, -1, 4))
    return torch.cat(cls_flat, dim=1), torch.cat(reg_flat, dim=1)      # 按 anchor 维度拼


if __name__ == "__main__":
    # 自检：造一个假 batch，看三层输出形状 + anchor 总数
    net = RetinaNet(pretrained=False)                 # 自检不下载权重
    x = torch.randn(2, 3, 320, 320)                   # 假输入
    cls_list, reg_list, anchors = net(x)              # 前向
    for i, (c, r) in enumerate(zip(cls_list, reg_list)):
        print(f"[retinanet] P{i + 3} cls={tuple(c.shape)} reg={tuple(r.shape)}")
    print("[retinanet] anchors:", tuple(anchors.shape))   # 期望 (18900,4)
    print("[retinanet] anchors[:1]:", anchors[0].tolist())
```

**预期输出（Day 1 下午的验收）**：

```text

[retinanet] P4 cls=(2, 180, 20, 20) reg=(2, 36, 20, 20)
[retinanet] P5 cls=(2, 180, 10, 10) reg=(2, 36, 10, 10)
```

```python
# 文件：data/voc.py
# 核心作用：把 VOC2007 的 (jpg + xml) 读成 (图像张量, 框, 类别)，供 DataLoader 使用
# 运行自检：python -m data.voc

voc_classes = (
    "aeroplane", "bicycle", "bird", "boat", "bottle",
    "bus", "car", "cat", "chair", "cow",
    "diningtable", "dog", "horse", "motorbike", "person",
    "pottedplant", "sheep", "sofa", "train", "tvmonitor",
)
class_to_idx = {name: i for i, name in enumerate(voc_classes)}      # 类别名 → 0..19

# ImageNet 归一化参数（ResNet 预训练权重就是按这个分布训的，必须保持一致）
mean = np.array([0.485, 0.456, 0.406], dtype=np.float32)            # 三通道均值
std = np.array([0.229, 0.224, 0.225], dtype=np.float32)             # 三通道标准差


class VOCDataset(Dataset):
    """功能：VOC2007 检测数据集
    输入：split ∈ {"train","val"}；img_size 默认取 config.img_size=320
    输出：每项 = (image[3,H,W] float32, boxes[N,4] float32 xyxy, labels[N] int64)
    调用位置：trainer/train.py 的 build_loader()；trainer/eval.py 的 evaluate()
    """

    def __init__(self, split="train", img_size=img_size):
        # 读取 8.1 生成的 id 列表
        ids = (split_dir / f"{split}.txt").read_text().split()
        self.ids = [x.strip() for x in ids if x.strip()]            # 清洗
        self.img_dir = data_root / "JPEGImages"                     # 图片目录
        self.ann_dir = data_root / "Annotations"                    # 标注目录
        self.img_size = img_size                                    # 统一缩放到 320×320

    def __len__(self):
        """功能：返回样本数；输入：无；输出：int；调用位置：DataLoader 采样时自动调用"""
        return len(self.ids)

    def __getitem__(self, idx):
        """功能：读取第 idx 个样本并转成训练格式
        输入：idx（int）
        输出：(image, boxes, labels) —— 见类注释
        调用位置：DataLoader 迭代时自动调用
        """
        image_id = self.ids[idx]                                    # 例如 "000012"
        img = Image.open(self.img_dir / f"{image_id}.jpg").convert("RGB")  # 统一 3 通道
        ow, oh = img.size                                           # 原图宽高（用于缩放框）
        img = img.resize((self.img_size, self.img_size), Image.BILINEAR)   # 直接拉伸到 320
        arr = np.asarray(img, dtype=np.float32) / 255.0             # HWC, 0~1
        arr = (arr - mean) / std                                    # 按 ImageNet 标准化
        image = torch.from_numpy(arr).permute(2, 0, 1).contiguous() # HWC → CHW

        boxes, labels = [], []                                      # 收集框与标签
        root = ET.parse(self.ann_dir / f"{image_id}.xml").getroot() # 解析 XML
        for obj in root.iter("object"):                             # 遍历每个目标
            name = obj.find("name").text.strip()                    # 类别名
            if name not in class_to_idx:                            # 跳过 VOC 未使用的类
                continue
            b = obj.find("bndbox")                                  # 边框节点
            x1 = float(b.find("xmin").text)                         # 左上 x
            y1 = float(b.find("ymin").text)                         # 左上 y
            x2 = float(b.find("xmax").text)                         # 右下 x
            y2 = float(b.find("ymax").text)                         # 右下 y
            sx, sy = self.img_size / ow, self.img_size / oh         # 缩放比例
            x1, x2 = x1 * sx, x2 * sx                               # 框同步缩放
            y1, y2 = y1 * sy, y2 * sy
            if x2 - x1 < 2 or y2 - y1 < 2:                          # 缩得太小 → 丢弃（否则回归不稳）
                continue
            boxes.append([x1, y1, x2, y2])                          # xyxy
            labels.append(class_to_idx[name])                       # 0..19

        if len(boxes) == 0:                                         # 极端情况：无目标
            boxes = torch.zeros((0, 4), dtype=torch.float32)
            labels = torch.zeros((0,), dtype=torch.int64)
        else:
            boxes = torch.tensor(boxes, dtype=torch.float32)        # 转张量
            labels = torch.tensor(labels, dtype=torch.int64)
        return image, boxes, labels                                 # 交给 collate_fn


def collate_fn(batch):
    """功能：把"每张图框数不同"的样本拼成 list（不能直接 stack）
    输入：batch = [(image, boxes, labels), ...]
    输出：(images[list of 3,H,W], boxes[list of N,4], labels[list of N])
    调用位置：DataLoader(collate_fn=collate_fn)；trainer/train.py 的 build_loader()
    """
    images = [b[0] for b in batch]                                  # 图像可以 stack，但放到训练循环里再 stack
    boxes = [b[1] for b in batch]                                   # 框数量不等 → 保持 list
    labels = [b[2] for b in batch]                                  # 标签同理
    return images, boxes, labels
```

```python
# 文件：utils/box.py
# 核心作用：框的 IoU、裁剪等基础运算
# 调用关系：losses/loss.py 的 assign_targets()、utils/metric.py、trainer/eval.py
import torch                                         # 张量


def box_iou(a, b):
    """功能：两组框两两算 IoU
    输入：a (N,4)、b (M,4)，均为 xyxy
    输出：(N,M) IoU 矩阵
    调用位置：losses/loss.py；utils/metric.py
    """
    area_a = (a[:, 2] - a[:, 0]).clamp(min=0) * (a[:, 3] - a[:, 1]).clamp(min=0)   # a 的面积
    area_b = (b[:, 2] - b[:, 0]).clamp(min=0) * (b[:, 3] - b[:, 1]).clamp(min=0)   # b 的面积
    lt = torch.max(a[:, None, :2], b[None, :, :2])        # 交集的左上角 (N,M,2)
    rb = torch.min(a[:, None, 2:], b[None, :, 2:])        # 交集的右下角
    wh = (rb - lt).clamp(min=0)                           # 交集宽高，负值截断
    inter = wh[..., 0] * wh[..., 1]                       # 交集面积
    union = area_a[:, None] + area_b[None, :] - inter     # 并集面积
    return inter / union.clamp(min=1e-6)                  # 防除 0


def clip_boxes(boxes, width, height):
    """功能：把框裁到图像范围内
    输入：boxes (N,4) xyxy；width/height 图像宽高
    输出：(N,4)
    调用位置：trainer/eval.py 的 postprocess()
    """
    boxes[:, 0::2] = boxes[:, 0::2].clamp(min=0, max=width)    # x1/x2
    boxes[:, 1::2] = boxes[:, 1::2].clamp(min=0, max=height)   # y1/y2
    return boxes
```

### 步骤 10｜损失：正负样本分配 + Focal Loss + 框回归

> **本步目的**：把 18900 个 anchor 分成正/负/忽略，再用 Focal Loss（分类）+ smooth L1（回归）得到可反传的 loss。
> **调用关系**：接收 `RetinaNet.forward` 的 `cls/reg/anchors` 与 `data/voc.py` 的 `gt_boxes/labels` → `Loss.forward` → `assign_targets` → `sigmoid_focal_loss`；下游是 `trainer/train.py` 的 `loss.backward()`。
> **验收**：`python -m tools.overfit_one` 让 1 张图的 loss 从 ~4.x 降到 <1.0（见步骤 11）。

#### 10.1 为什么"分配"比"损失"更重要

- 18900 个 anchor 里，**真正有物体的可能只有 3–10 个**，其余全是背景。
- 如果直接算交叉熵：背景占了 99.9%，模型学会"全预测背景"就能拿高分 → **loss 降得很快但 mAP=0**。
- 所以要先"分配"：谁算正样本、谁算负样本、谁不算（忽略），再用 **Focal Loss** 压制"容易的负样本"。

#### 10.2 损失代码（分配 + Focal + smooth L1）

```python
# 文件：losses/loss.py
# 核心作用：① 给 18900 个 anchor 分配正/负/忽略；② 算 Focal Loss（分类）+ smooth L1（回归）
# 调用关系：trainer/train.py 的 train_one_epoch() 调 Loss.forward()
#          依赖 utils/box.py 的 box_iou()、models/anchor.py 的 encode()
import torch                                         # 张量
import torch.nn as nn                                # Module
import torch.nn.functional as F                      # 损失函数
from utils.box import box_iou                        # IoU 矩阵
from models.anchor import encode                     # 框编码
from config.config import pos_iou, neg_iou, num_classes   # 阈值与类别数


def assign_targets(anchors, gt_boxes, gt_labels):
    """功能：为一张图的所有 anchor 分配标签与回归目标
    输入：anchors (N,4)；gt_boxes (M,4)；gt_labels (M,)
    输出：cls_t (N,C) float（正样本对应类=1，其余全 0）、reg_t (N,4)、pos (N,) bool、ignore (N,) bool
    调用位置：Loss.forward()（本文件下方）
    """
    n = anchors.shape[0]                             # anchor 数 18900
    device = anchors.device                          # 统一设备
    # 边界情况：这张图没有目标（VOC 里极少，但必须处理，否则 max() 会报错）
    if gt_boxes.numel() == 0:
        return (torch.zeros((n, num_classes), device=device),
                torch.zeros((n, 4), device=device),
                torch.zeros((n,), dtype=torch.bool, device=device),
                torch.zeros((n,), dtype=torch.bool, device=device))

    ious = box_iou(anchors, gt_boxes)                # (N,M)：每个 anchor 与每个 GT 的 IoU
    max_iou, idx = ious.max(dim=1)                   # 每个 anchor 最匹配的 GT 及其 IoU

    pos = max_iou >= pos_iou                         # IoU ≥0.5 → 正样本
    # 兜底：每个 GT 至少给它"最匹配的那个 anchor"一个正样本，避免小目标被漏
    best_anchor = ious.argmax(dim=0)                 # (M,) 每个 GT 的最佳 anchor
    pos[best_anchor] = True                          # 强制设为正样本
    # 关键：被强制的 anchor 可能原本匹配到别的 GT，这里把它的目标改回"它服务的那个 GT"
    idx[best_anchor] = torch.arange(gt_boxes.shape[0], device=device)
    matched = gt_boxes[idx]                          # (N,4) 每个 anchor 对应的 GT 框

    cls_t = torch.zeros((n, num_classes), device=device)          # 分类目标：多标签 one-hot
    cls_t[pos, gt_labels[idx[pos]]] = 1.0                          # 正样本：对应类置 1

    reg_t = torch.zeros((n, 4), device=device)                     # 回归目标
    if pos.any():                                                   # 只有正样本才有回归目标
        reg_t[pos] = encode(anchors[pos], matched[pos])             # 调 models/anchor.py

    ignore = (max_iou >= neg_iou) & (~pos)           # 0.4~0.5 之间：不参与 loss
    return cls_t, reg_t, pos, ignore


def sigmoid_focal_loss(logits, targets, alpha=0.25, gamma=2.0):
    """功能：Focal Loss（逐元素，不求和），公式 FL = -α_t (1-p_t)^γ log p_t
    输入：logits 任意形状；targets 同形状（0/1 软标签）
    输出：同形状的逐元素 loss
    调用位置：Loss.forward()
    """
    p = torch.sigmoid(logits)                                      # 预测概率
    ce = F.binary_cross_entropy_with_logits(logits, targets, reduction="none")   # 逐元素交叉熵
    p_t = p * targets + (1 - p) * (1 - targets)                    # 取"对应那一边"的概率
    loss = ce * (1 - p_t).pow(gamma)                               # 关键：易分样本 ×(1-p_t)^2
    alpha_t = alpha * targets + (1 - alpha) * (1 - targets)        # 类别权重 α
    return alpha_t * loss                                          # 返回逐元素值


class Loss(nn.Module):
    """功能：总损失 = (Focal Loss + smooth L1) / 正样本数
    输入：cls (B,N,C)、reg (B,N,4)、anchors (N,4)、gt_boxes(list[M,4])、gt_labels(list[M])
    输出：(loss 标量, stats 字典)
    调用位置：trainer/train.py 的 train_one_epoch()
    """

    def forward(self, cls, reg, anchors, gt_boxes, gt_labels):
        # 用 0 维张量累加（不能写 0.0：若整批没有正样本，float 没有 .item() 会报错）
        cls_sum = torch.zeros((), device=cls.device)  # 累计分类损失
        reg_sum = torch.zeros((), device=cls.device)  # 累计回归损失
        num_pos = 0                                  # 累计正样本数（用于归一化）
        for b in range(cls.shape[0]):                # 逐张图（框数不同，不能向量化）
            cls_t, reg_t, pos, ignore = assign_targets(anchors, gt_boxes[b], gt_labels[b])
            valid = ~ignore                          # 参与分类的 anchor（正 + 真负）
            cls_sum = cls_sum + sigmoid_focal_loss(cls[b][valid], cls_t[valid]).sum()
            if pos.any():                            # 有正样本才算回归
                reg_sum = reg_sum + F.smooth_l1_loss(reg[b][pos], reg_t[pos],
                                                     reduction="sum", beta=1 / 9)
                num_pos += int(pos.sum().item())
        num_pos = max(num_pos, 1)                    # 防止除 0
        total = (cls_sum + reg_sum) / num_pos        # RetinaNet 原文：用正样本数归一化
        stats = {"cls": cls_sum.item() / num_pos, "reg": reg_sum.item() / num_pos, "num_pos": num_pos}
        return total, stats
```

> **本步可改**：`gamma` 调大更关注难样本（过大训练不稳）；`alpha` 是正样本权重，类别极不均衡可试 0.5；`pos_iou / neg_iou` 调低召回高但噪声大、调高更干净但漏检多；smooth L1 的 `beta=1/9` 调大对异常框更宽容。

```python
def main():
```

```python
    random.seed(seed)                                # Python
    np.random.seed(seed)                             # NumPy
    torch.manual_seed(seed)                          # CPU 上的 torch
    torch.cuda.manual_seed_all(seed)                 # 所有 GPU
    torch.backends.cudnn.deterministic = True        # cuDNN 确定性（略慢，但可复现）
    torch.backends.cudnn.benchmark = False


def build_loader(split, batch_size):
    """功能：构造 DataLoader
    输入：split ∈ {"train","val"}；batch_size
    输出：DataLoader
    调用位置：main()
    """
    ds = VOCDataset(split)                         # data/voc.py
    return DataLoader(ds, batch_size=batch_size, shuffle=(split == "train"),
                      num_workers=num_workers, collate_fn=collate_fn,
                      drop_last=(split == "train"), pin_memory=True)


def train_one_epoch(model, loader, criterion, optimizer, scaler, device, epoch, writer):
    """功能：训练一个 epoch
    输入：模型/数据/损失/优化器/AMP scaler/设备/轮次/日志器
    输出：本 epoch 平均 loss（float）
    调用位置：main() 的 for epoch 循环
    """
    model.train()                                    # 切训练模式（BN/Dropout 生效）
    # 注意：model.train() 会把 BN 全部切回训练态，所以这里要把 stem 的 BN 再冻结一次
    for m in model.backbone.stem.modules():
        if isinstance(m, torch.nn.BatchNorm2d):
            m.eval()                                 # 只用 running_mean/var，不更新统计量
    total, n = 0.0, 0                                # 累计 loss 与步数
    for step, (images, boxes, labels) in enumerate(loader):
        images = torch.stack(images).to(device, non_blocking=True)   # list → (B,3,320,320)
        boxes = [b.to(device) for b in boxes]                        # 框搬到 GPU
        labels = [l.to(device) for l in labels]                      # 标签搬到 GPU

        optimizer.zero_grad(set_to_none=True)                        # 清梯度
        with torch.cuda.amp.autocast():                              # 混合精度，省显存
            cls_list, reg_list, anchors = model(images)              # 前向
            cls, reg = flatten_outputs(cls_list, reg_list)           # 展平
            loss, stats = criterion(cls, reg, anchors, boxes, labels)  # 算损失

        scaler.scale(loss).backward()                                # 反向（带缩放）
        scaler.unscale_(optimizer)                                   # 还原梯度以便裁剪
        torch.nn.utils.clip_grad_norm_(model.parameters(), 10.0)     # 梯度裁剪，防爆炸
        scaler.step(optimizer)                                       # 更新参数
        scaler.update()                                              # 更新缩放系数

        total += loss.item()                                         # 累计
        n += 1
        if step % 20 == 0:                                           # 每 20 步打印
            print(f"[E{epoch} {step}/{len(loader)}] loss={loss.item():.4f} "
                  f"cls={stats['cls']:.4f} reg={stats['reg']:.4f} pos={stats['num_pos']}")
            writer.add_scalar("train/loss_step", loss.item(), epoch * len(loader) + step)
    return total / max(n, 1)                                         # 平均


def main():
    """功能：训练入口（解析参数 → 建模型 → 循环训练 → 存权重）
    输入：命令行 --epochs/--batch/--resume
    输出：checkpoints/last.pth + runs/ 日志
    调用位置：`python -m trainer.train`
    """
    parser = argparse.ArgumentParser()
    parser.add_argument("--epochs", type=int, default=epochs)         # 轮数
    parser.add_argument("--batch", type=int, default=batch_size)      # batch 大小
    parser.add_argument("--exp", type=str, default=time.strftime("EXP-%m%d-%H%M"))  # 实验编号（15.2）
    parser.add_argument("--resume", type=str, default="")             # 断点续训（可选）
    args = parser.parse_args()

    set_seed()                                                        # 固定种子
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    ckpt_dir.mkdir(parents=True, exist_ok=True)                       # 建目录
    run_dir.mkdir(parents=True, exist_ok=True)

    model = RetinaNet(pretrained=True).to(device)                     # 模型上 GPU
    # 6GB 优化：冻结 stem 里的 BN（不更新统计量），省显存且小 batch 更稳
    for m in model.backbone.stem.modules():
        if isinstance(m, torch.nn.BatchNorm2d):
            m.eval()
            m.requires_grad_(False)

    criterion = Loss()                                       # 损失
    params = [p for p in model.parameters() if p.requires_grad]        # 可训练参数
    optimizer = torch.optim.AdamW(params, lr=lr, weight_decay=weight_decay)
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=args.epochs)
    scaler = torch.cuda.amp.GradScaler()                              # AMP
    run_dir = run_dir / args.exp                                      # runs/EXP-002/
    writer = SummaryWriter(str(run_dir))                              # 日志写到实验目录
    dump_run_config(run_dir, {"epochs": args.epochs, "batch": args.batch})  # 落盘 config.json（实验日志要用）

    if args.resume:                                                   # 续训
        ckpt = torch.load(args.resume, map_location=device)
        model.load_state_dict(ckpt["model"])

    loader = build_loader("train", args.batch)                        # 训练集
    for epoch in range(args.epochs):                                  # 逐轮
        avg = train_one_epoch(model, loader, criterion, optimizer, scaler, device, epoch, writer)
        scheduler.step()                                              # 学习率余弦衰减
        writer.add_scalar("train/loss_epoch", avg, epoch)             # 记录
        writer.add_scalar("train/lr", optimizer.param_groups[0]["lr"], epoch)
        torch.save({"model": model.state_dict(), "epoch": epoch}, ckpt_dir / "last.pth")  # 存权重
        print(f"[epoch {epoch}] avg_loss={avg:.4f} -> saved checkpoints/last.pth")
    writer.close()                                                    # 关闭日志


if __name__ == "__main__":
    main()
```

### 步骤 13｜评估：VOC mAP@0.5

> **本步目的**：把预测框与 GT 按 VOC 口径算每类 AP，再平均成 mAP@0.5。
> **调用关系**：`trainer/eval.py:main` → `evaluate` → `postprocess`（用 `models/anchor.py:decode`）→ `compute_map` → `voc_ap`（用 `utils/box.py:box_iou`）。
> **验收**：`python -m trainer.eval --ckpt checkpoints/last.pth --exp EXP-002` 打印每类 AP + mAP（可以低，但不能报错或为 None）。

#### 13.1 5 分钟讲清 mAP

1. **TP / FP**：预测框和某个 GT 的 IoU ≥ 0.5 且该 GT 没被占 → TP；否则 FP。
2. **按分数排序**：把所有预测框按置信度从高到低排，逐个判 TP/FP。
3. **Precision / Recall 曲线**：每判一个框就更新一次 `P = TP/(TP+FP)`、`R = TP/(TP+FN)`。
4. **AP**：PR 曲线下的面积（本代码用"全点插值"）。
5. **mAP**：20 个类的 AP 求平均。**没有 GT 的类不参与平均**（否则会被 0 拉低）。

> **一句话**：mAP 衡量的是"**排在前面的框是不是又对又全**"。

#### 13.2 mAP 计算代码

```python
# 文件：utils/metric.py
# 核心作用：VOC 口径的 AP / mAP@0.5 计算
# 调用关系：trainer/eval.py 的 evaluate() 调 compute_map()
import numpy as np                                   # 数组运算
import torch                                         # 张量
from utils.box import box_iou                        # IoU 矩阵


def voc_ap(rec, prec):
    """功能：由 PR 序列算 AP（全点插值）
    输入：rec、prec —— numpy 数组，已按分数降序
    输出：float
    调用位置：compute_map()
    """
    mrec = np.concatenate(([0.0], rec, [1.0]))       # 两端补点
    mpre = np.concatenate(([0.0], prec, [0.0]))
    for i in range(mpre.size - 1, 0, -1):            # 从右往左做"单调不增"包络
        mpre[i - 1] = max(mpre[i - 1], mpre[i])
    idx = np.where(mrec[1:] != mrec[:-1])[0]         # recall 发生变化的点
    return float(np.sum((mrec[idx + 1] - mrec[idx]) * mpre[idx + 1]))   # 面积求和


def compute_map(detections, gts, num_classes=20, iou_thr=0.5):
    """功能：对整个验证集算每类 AP 与 mAP
    输入：detections = list[dict(boxes(T,4), scores(T,), labels(T,))]（每张图的预测）
          gts        = list[dict(boxes(M,4), labels(M,))]（每张图的真值，顺序一致）
    输出：(mAP: float, aps: dict[类别id → AP])
    调用位置：trainer/eval.py 的 evaluate()
    """
    aps = {}                                         # 每类 AP
    for c in range(num_classes):                     # 逐类算
        scores_all, tp_all, npos = [], [], 0         # 该类所有图的预测分数 / TP 标记 / GT 总数
        for det, gt in zip(detections, gts):         # 逐图
            gmask = gt["labels"] == c                # 该类的 GT
            gboxes = gt["boxes"][gmask]
            npos += int(gboxes.shape[0])             # 累计该类 GT 数（分母）
            dmask = det["labels"] == c               # 该类的预测
            dboxes = det["boxes"][dmask]
            dscores = det["scores"][dmask]
            if dboxes.numel() == 0:                  # 该图没预测这个类 → 跳过
                continue
            order = dscores.argsort(descending=True) # 按分数降序
            dboxes, dscores = dboxes[order], dscores[order]
            # 与该图该类 GT 算 IoU（GT 为空时给 0 列，避免报错）
            ious = box_iou(dboxes, gboxes) if gboxes.numel() > 0 else torch.zeros((len(dboxes), 0))
            used = torch.zeros(len(gboxes), dtype=torch.bool)   # 标记该 GT 已被匹配
            for i in range(len(dboxes)):             # 逐预测框判 TP/FP
                if gboxes.numel() == 0:              # 没 GT → 必然 FP
                    tp = 0
                else:
                    j = int(ious[i].argmax())        # 最匹配的 GT
                    if ious[i, j] >= iou_thr and not used[j]:
                        used[j] = True               # 占住这个 GT
                        tp = 1
                    else:
                        tp = 0
                tp_all.append(tp)                    # 记录
                scores_all.append(float(dscores[i]))
        if npos == 0:                                # 该类在验证集没有 GT → 不参与 mAP
            continue
        order = np.argsort(-np.array(scores_all))    # 全局再按分数排序
        tp_arr = np.array(tp_all)[order].astype(np.float32)
        fp_arr = 1.0 - tp_arr
        tp_cum = np.cumsum(tp_arr)                   # 累计 TP
        fp_cum = np.cumsum(fp_arr)                   # 累计 FP
        rec = tp_cum / max(npos, 1)                  # Recall
        prec = tp_cum / np.maximum(tp_cum + fp_cum, 1e-6)   # Precision
        aps[c] = voc_ap(rec, prec)                   # 该类 AP
    mAP = float(np.mean(list(aps.values()))) if aps else 0.0
    return mAP, aps
```

#### 13.3 推理 + 评估脚本

```python
# 文件：trainer/eval.py
# 核心作用：加载权重 → 在 val 上逐图推理（decode + NMS）→ 算 mAP@0.5
# 运行：python -m trainer.eval --ckpt checkpoints/last.pth --exp EXP-002
# 调用关系：models/retinanet.py（前向）、models/anchor.py（decode）、utils/metric.py（mAP）
import argparse                                      # 命令行参数
import torch                                         # 张量
from torchvision.ops import nms                      # 官方 NMS（C++ 实现，快）
from config.config import (img_size, num_classes, nms_thr, score_thr,
                            topk_per_img, run_dir)   # 常量
from data.voc import VOCDataset, voc_classes        # 数据集 + 类别名
from models.retinanet import RetinaNet, flatten_outputs   # 模型
from models.anchor import decode                     # 解码
from utils.box import clip_boxes                     # 裁剪
from utils.metric import compute_map                 # mAP
from utils.misc import save_json                     # 指标落盘（12.5）


@torch.no_grad()                                     # 评估不需要梯度，省显存
def postprocess(cls, reg, anchors, score_thr=score_thr, nms_thr=nms_thr, topk=topk_per_img):
    """功能：把单张图的原始输出变成最终检测框
    输入：cls (N,C) logits、reg (N,4) 偏移、anchors (N,4)
    输出：dict(boxes(T,4), scores(T,), labels(T,))
    调用位置：evaluate()
    """
    scores = torch.sigmoid(cls)                      # (N,C) 概率
    boxes = decode(anchors, reg)                     # (N,4) 先全部解码
    out_b, out_s, out_l = [], [], []                 # 收集每类结果
    for c in range(scores.shape[1]):                 # 逐类
        s = scores[:, c]                             # 该类分数
        keep = s > score_thr                         # 先滤低分
        if int(keep.sum()) == 0:                     # 该类没有候选
            continue
        b, s2 = boxes[keep], s[keep]
        if s2.numel() > 1000:                        # 太多就先取 top1000
            top = torch.topk(s2, 1000).indices
            b, s2 = b[top], s2[top]
        idx = nms(b, s2, nms_thr)                    # NMS 去重
        out_b.append(b[idx][:topk])                  # 最多保留 topk
        out_s.append(s2[idx][:topk])
        out_l.append(torch.full((len(idx[:topk]),), c, dtype=torch.long, device=cls.device))
    if not out_b:                                    # 全图为空
        z = torch.zeros((0, 4), device=cls.device)
        return {"boxes": z, "scores": z.new_zeros((0,)), "labels": z.new_zeros((0,), dtype=torch.long)}
    return {"boxes": torch.cat(out_b), "scores": torch.cat(out_s), "labels": torch.cat(out_l)}


def evaluate(ckpt_path, exp="EXP-002"):
    """功能：遍历验证集 → 推理 → 算 mAP
    输入：ckpt 路径、exp（实验编号，用于写 runs/EXP-xxx/metrics.json）
    输出：(mAP, aps)
    调用位置：`python -m trainer.eval` 的 main()
    """
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model = RetinaNet(pretrained=False).to(device)            # 不需要下载预训练
    ckpt = torch.load(ckpt_path, map_location=device)          # 读权重
    model.load_state_dict(ckpt["model"])
    model.eval()                                               # 评估模式

    ds = VOCDataset("val")                                   # 验证集
    dets, gts = [], []                                         # 预测 / 真值
    for i in range(len(ds)):                                   # 逐图（一张一张，省显存）
        img, boxes, labels = ds[i]
        with torch.no_grad():                                  # 推理不建计算图，省显存
            cls_list, reg_list, anchors = model(img.unsqueeze(0).to(device))
            cls, reg = flatten_outputs(cls_list, reg_list)
            det = postprocess(cls[0], reg[0], anchors)          # 解码 + NMS
        det["boxes"] = clip_boxes(det["boxes"], img_size, img_size)
        dets.append({k: v.cpu() for k, v in det.items()})       # 存到 CPU
        gts.append({"boxes": boxes, "labels": labels})
        if i % 100 == 0:
            print(f"[eval] {i}/{len(ds)}")

    mAP, aps = compute_map(dets, gts, num_classes)             # 算 mAP（utils/metric.py）
    print(f"[eval] mAP@0.5 = {mAP * 100:.2f}%")
    for c, ap in sorted(aps.items()):                          # 逐类打印
        print(f"  {voc_classes[c]:12s} AP={ap * 100:5.1f}")
    save_json(run_dir / exp / "metrics.json",                  # 实验日志的结果原文
              {"mAP": mAP, "ap": {voc_classes[c]: a for c, a in aps.items()}})
    return mAP, aps


def main():
    """功能：解析参数并调用 evaluate；输入：--ckpt/--exp；输出：控制台 mAP + metrics.json；调用位置：__main__"""
    parser = argparse.ArgumentParser()
    parser.add_argument("--ckpt", type=str, default="checkpoints/last.pth")
    parser.add_argument("--exp", type=str, default="EXP-002")   # 与训练时的实验编号一致
    args = parser.parse_args()
    evaluate(args.ckpt, args.exp)


if __name__ == "__main__":
    main()
```

| 忘记 `model.eval()`          | mAP 抖动很大、BN 用 batch 统计量     | 评估前必须 `model.eval()`（代码已写）                       |
| 坐标没裁到图内                    | 框跑到图像外、IoU 计算异常              | `clip_boxes`（代码已写）                              |

### 步骤 14｜推理可视化

> **本步目的**：把预测框画回原图，作为报告里的定性证据（mAP 是数字，图是直观说服力）。
> **调用关系**：`tools/predict.py:main` → `load_image` → `RetinaNet.forward` → `decode` → `postprocess` → 画框保存。
> **验收**：`python -m tools.predict --img <图片>` 输出 ≥1 张带框图到 `docs/figures/`，框与类别肉眼合理。

```python
# 文件：tools/predict.py
# 核心作用：单张图片推理 → 画框 → 保存结果图（报告里要用）
# 运行：python -m tools.predict --img data\VOCdevkit\VOC2007\JPEGImages\000001.jpg
# 调用关系：models/retinanet.py（前向）、models/anchor.py（decode）、trainer/eval.py（postprocess）
import argparse                                      # 参数
import numpy as np                                   # 像素处理
import torch                                         # 张量
from PIL import Image, ImageDraw                     # 读写图 + 画框
from config.config import img_size, score_thr       # 常量
from data.voc import voc_classes, mean, std          # 类别名 + 归一化参数
from models.retinanet import RetinaNet, flatten_outputs   # 模型
from trainer.eval import postprocess                 # 复用评估里的后处理


def load_image(path):
    """功能：读图 → 归一化张量 + 缩放后的 PIL 图
    输入：path（str）
    输出：(tensor(1,3,320,320), pil_img(320,320))
    调用位置：main()
    """
    pil = Image.open(path).convert("RGB").resize((img_size, img_size), Image.BILINEAR)
    arr = np.asarray(pil, dtype=np.float32) / 255.0              # 0~1
    arr = (arr - mean) / std                                     # 与训练一致
    tensor = torch.from_numpy(arr).permute(2, 0, 1).unsqueeze(0).float()
    return tensor, pil


def main():
    """功能：推理一张图并保存画框结果
    输入：--img 图片路径、--ckpt 权重、--out 输出路径
    输出：带框图片（默认 runs/pred.jpg）
    调用位置：`python -m tools.predict`
    """
    parser = argparse.ArgumentParser()
    parser.add_argument("--img", type=str, required=True)        # 输入图
    parser.add_argument("--ckpt", type=str, default="checkpoints/last.pth")
    parser.add_argument("--out", type=str, default="runs/pred.jpg")
    parser.add_argument("--thr", type=float, default=score_thr)  # 阈值可调
    args = parser.parse_args()

    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model = RetinaNet(pretrained=False).to(device)
    model.load_state_dict(torch.load(args.ckpt, map_location=device)["model"])
    model.eval()                                                 # 推理模式

    tensor, pil = load_image(args.img)                           # 预处理
    with torch.no_grad():
        cls_list, reg_list, anchors = model(tensor.to(device))
        cls, reg = flatten_outputs(cls_list, reg_list)
        det = postprocess(cls[0], reg[0], anchors, score_thr=args.thr)   # 后处理

    draw = ImageDraw.Draw(pil)                                   # 在 320 图上画
    for box, score, label in zip(det["boxes"].cpu(), det["scores"].cpu(), det["labels"].cpu()):
        x1, y1, x2, y2 = [float(v) for v in box]                 # 取坐标
        draw.rectangle([x1, y1, x2, y2], outline="red", width=2) # 画框
        draw.text((x1 + 2, y1 + 2), f"{voc_classes[int(label)]} {float(score):.2f}", fill="red")
    pil.save(args.out)                                           # 保存
    print(f"[predict] 检测到 {len(det['scores'])} 个框，已保存 {args.out}")


if __name__ == "__main__":
    main()
```

> **报告里要用的图**：至少 1 张"预测框 + 类别 + 分数"的图；有 GT 的话再画一张对比图更好。

> **本步可改**：换图片即可（建议 1 张容易的 + 1 张拥挤/小目标的，报告里对比）；画图阈值 0.3 只影响显示，不影响 mAP。

### A.2 第 2 周（骨干网络与增强模块）

| 术语                           | 一句话解释                                                        | 首次出现 |
| ---------------------------- | ------------------------------------------------------------ | ---- |
| **ReLU**                     | `max(0, x)`，把负数归零；比 sigmoid 梯度好传                             | 6.1  |
| **Dropout**                  | 训练时随机"关掉"一部分神经元，防过拟合                                         | 6.1  |
| **lrN（局部响应归一化）**             | AlexNet 用的老式归一化，现在基本被 BN 取代                                  | 6.1  |
| **感受野（RF）**                  | 输出上一个点"看到"原图多大区域                                             | 6.2  |
| **3×3 堆叠**                   | 两个 3×3 卷积的感受野 = 一个 5×5，但参数更少、非线性更多                           | 6.2  |
| **BN（Batch Normalization）**  | 每层按 batch 统计量归一化，再用 γ/β 缩放平移                                 | 6.3  |
| **internal covariate shift** | 深层输入分布随训练漂移，BN 原论文给出的动机                                      | 6.3  |
| **退化问题（degradation）**        | 网络加深后训练误差反而变大；**不是过拟合**                                      | 6.4  |
| **残差连接（shortcut）**           | `H(x) = F(x) + x`，让梯度能"抄近路"回传                                | 6.4  |
| **BasicBlock / Bottleneck**  | ResNet-18/34 用两块 3×3 / ResNet-50+ 用 1×1-3×3-1×1（expansion=4） | 6.4  |
| **cardinality**              | ResNeXt 的"分组数"，把通道分成 G 组各算各的再拼                               | 6.5  |
| **膨胀卷积（Dilated Conv）**       | 卷积核中间"插空"，不增参数就扩大感受野                                         | 6.6  |
| **膨胀率 r**                    | 插空的比例；r=1 就是普通卷积                                             | 6.6  |
| **网格效应（gridding）**           | 膨胀卷积叠太多导致采样点离散、漏掉连续像素                                        | 6.6  |
| **可变形卷积（DeformConv）**        | 给每个采样点学一个偏移量，卷积核"跟着形状走"                                      | 6.7  |
| **offset**                   | 可变形卷积里预测出来的采样点偏移；3×3 核是 18 通道（2·3·3）                         | 6.7  |
| **双线性插值**                    | 偏移后坐标是小数，用周围 4 个点加权取值；保证可导                                   | 6.7  |
| **modulation（v2）**           | DeformConv v2 增加的"每个采样点多重要"权重（0~1）                           | 6.7  |
| **FPN**                      | 自顶向下 + 横向 1×1 连接，把多尺度特征融合                                    | 6.8  |
| **最近邻上采样**                   | 把小特征图直接"复制放大"，FPN 用的方式                                       | 6.8  |
| **SE 模块**                    | GAP 压缩 → FC 降维再升维 → sigmoid 得到通道权重 → 乘回原特征                   | 6.9  |
| **GAP（全局平均池化）**              | 每个通道求平均，H×W → 1 个数                                           | 6.9  |

### A.3 第 3 周（目标检测与 Transformer）

| 术语                               | 一句话解释                                            | 首次出现      |
| -------------------------------- | ------------------------------------------------ | --------- |
| **两阶段检测**                        | 先出候选区域（RPN），再对每个区域分类+回归                          | 7.1       |
| **RPN**                          | 区域建议网络，3×3 卷积 + 两个 1×1（分类/回归）                    | 7.1       |
| **anchor**                       | 预设的参考框（3 尺度 × 3 比例 = 9 个/位置）                     | 7.1       |
| **IoU**                          | 两个框的交集面积 / 并集面积                                  | 7.1       |
| **RoI Pooling / Align**          | 把任意大小的候选区域池化成固定 7×7                              | 7.1       |
| **quality mismatch**             | 训练用的低质量框与测试用的高质量框分布不一致                           | 7.2       |
| **级联（cascade）**                  | 多级检测头逐级提高 IoU 阈值（0.5→0.6→0.7）                    | 7.2       |
| **网格（grid）**                     | YOLO 把图切成 S×S 格，每格负责中心落在其中的物体                    | 7.3       |
| **confidence**                   | YOLO 的"这里有物体的概率 × 框的 IoU"                        | 7.3       |
| **NMS（非极大值抑制）**                  | 按分数排序，把与高分框 IoU 过高的框删掉                           | 7.3       |
| **anchor-free**                  | 不预设参考框，直接预测点/角点/中心                               | 7.5 / 7.7 |
| **解耦头（decoupled head）**          | 分类和回归用两套独立分支，不共享最后的卷积                            | 7.5       |
| **TAL（Task-Aligned Assigner）**   | YOLOv8 的正样本分配策略，按分类分与 IoU 联合打分                   | 7.5       |
| **DFL（Distribution Focal Loss）** | 把框的 4 条边当"分布"来回归，而非直接回归一个数                       | 7.5       |
| **Focal Loss**                   | `−α_t(1−p_t)^γ log p_t`，压低易分负样本的权重               | 7.6       |
| **easy negative**                | 一眼就知道是背景的负样本，数量极多，会淹没正样本                         | 7.6       |
| **正负样本不平衡（1:1000）**              | 一张图里候选框绝大多数是背景                                   | 7.6       |
| **角点检测（CornerNet）**              | 检测左上/右下两个角点，再用 embedding 配对                      | 7.7       |
| **CenterNet**                    | 只检测物体中心点，再回归宽高                                   | 7.7       |
| **自注意力（self-attention）**         | `softmax(QKᵀ/√d_k)V`，每个位置和所有位置算相关度               | 7.8       |
| **Q / K / V**                    | 查询 / 键 / 值；像查字典：拿 Q 和所有 K 比对，按权重取 V              | 7.8       |
| **多头注意力（MHA）**                   | 把特征分成 h 份，各自算注意力再拼接                              | 7.8       |
| **位置编码（PE）**                     | 给序列每个位置加"位置信息"；Transformer 用 sin/cos，ViT 用可学习 1D | 7.8 / 7.9 |
| **LayerNorm**                    | 对每个样本的特征维归一化（Transformer 用，不用 BN）                | 7.8       |
| **O(N²)**                        | 注意力要算 N×N 对，序列变长时计算量平方增长                         | 7.8       |
| **patch embedding**              | 把 16×16×3 的图块拉平成 768 维向量                         | 7.9       |
| **[CLS] token**                  | ViT 额外加的可学习分类 token，用它的输出做分类                     | 7.9       |
| **归纳偏置（inductive bias）**         | 模型自带的结构先验（CNN 有局部性/平移等变，Transformer 没有）          | 7.9       |
| **object query**                 | DETR 的 100 个可学习"检测槽位"向量，不是 anchor                | 7.10      |
| **匈牙利匹配**                        | 训练时把预测与真值做一对一最优分配                                | 7.10      |
| **set prediction**               | 把检测当"输出一个集合"，而非"逐框分类"                            | 7.10      |
| **no-object**                    | DETR 分类头的第 C+1 类，表示"这个槽位没有物体"                    | 7.10      |
| **GIoU**                         | 广义 IoU，额外考虑"最小外接框"，对小框更公平                        | 7.10      |
| **可变形注意力**                       | 每个 query 只在 K 个可学习偏移点上采样，O(N·K)                  | 7.11      |
| **多尺度可变形注意力**                    | 在 C3/C4/C5 三层上各采 K 点，共 3K 个                      | 7.11      |
| **自监督预训练**                       | 不用人工标签，用"遮挡-重建"这类代理任务学特征                         | 7.12      |
| **代理任务（pretext task）**           | 自己构造的"假任务"，如遮住一部分让模型补                            | 7.12      |
| **线性探针（linear probing）**         | 冻结 encoder、只训一个线性分类器，测特征质量                       | 7.12      |
| **SSM（状态空间模型）**                  | `h_t = A h_{t-1} + B x_t`，带记忆的线性递推               | 7.13      |
| **选择性（selective）**               | Mamba 让 B/C/Δ 随输入变化，学会"该记什么"                     | 7.13      |
| **交叉扫描（CSM）**                    | VMamba 按四个方向扫 2D 图，转成 1D 序列再融合                   | 7.13      |

## 附录 E 常见坑清单（报错时先查这里）

### E.1 环境类

| 现象                                                    | 根因                          | 解法                                                                                                |
| ----------------------------------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------- |
| `python` 跑起来不是你装的库                                    | **Trae 自带 Python 劫持 PATH**  | 必须 `conda activate cv`，再用 `python -c "import sys;print(sys.executable)"` 验证是 `envs\cv\python.exe` |
| `activate` 不是内部或外部命令                                  | PATH 没含 Anaconda Scripts    | 敲全路径 `D:\anaconda3\Scripts\activate.bat`，或先 `where activate` 查                                    |
| `torch.cuda.is_available()` = False                   | 装了 CPU 版 torch              | `pip list` 看版本号有没有 `+cu`；没有就 `pip uninstall torch torchvision -y` 后按 3.1 步骤 5 重装                  |
| `Failed to initialize NumPy` / `_ARRAY_API not found` | NumPy 2.x 与 torch 2.0.1 不兼容 | `pip install "numpy<2"`                                                                           |
| 装 torch 从清华镜像下载                                       | 镜像只有 CPU 版                  | 只能用 `--index-url https://download.pytorch.org/whl/cu118`（或 cu121）                                 |
| 磁盘不够                                                  | torch 占 2.3 GB + 缓存         | `pip cache purge`；环境装在 D 盘                                                                        |

### E.2 训练 / 显存类

| 现象                                            | 根因                      | 解法                                                  |
| --------------------------------------------- | ----------------------- | --------------------------------------------------- |
| `CUDA out of memory`                          | 显存不够（你是 6 GB）           | 依次试：减小 batch → 减小 imgsz → 冻结 backbone → 梯度累积 → 换小模型 |
| `RuntimeError: expected scalar type ...`      | 模型和输入的 dtype/device 不一致 | `.to(device)` 要作用于模型**和**输入；半精度要统一                  |
| loss 一直是 `nan`                                | 学习率太大 / 数据没归一化 / log(0) | 降 lr（1e-3 → 1e-4）；检查归一化；给 log 加 eps                 |
| loss 不降                                       | lr 太小 / 标签错 / 数据没打乱     | 先跑 1 个 batch 过拟合测试（能过拟合说明模型没问题）                     |
| BN 报 `Expected more than 1 value per channel` | batch size = 1          | batch ≥ 2，或把 BN 换成 GroupNorm（检测小 batch 常用）          |
| 准确率卡在 10%（CIFAR-10）                           | 学习率/初始化/数据增强有问题         | 用 lr=0.001 + Adam 先跑通，再换 SGD                        |

### E.3 论文 / Zotero 类

| 现象             | 根因         | 解法                                      |
| -------------- | ---------- | --------------------------------------- |
| Zotero 抓不到 PDF | 出版商反爬      | 用学校 VPN / arXiv 版本；或手动下载后拖进 Zotero      |
| Zotero 条目元数据错乱 | 抓取时匹配到同名论文 | 右键 → "抓取 PDF 元数据" 重新抓；核对 DOI            |
| AI 说的内容和原文对不上  | 模型幻觉       | **三色法**：🟩 有原文 / 🟨 推断 / 🟥 删（第 5 章 S4） |
| 论文里的数字记不住      | 正常         | 笔记里只记**结论量级 + 出处表号**，不背精确值              |

### E.4 开源工程类（YOLOv8 / transformers）

| 现象                                      | 根因                    | 解法                                                        |
| --------------------------------------- | --------------------- | --------------------------------------------------------- |
| `pip install ultralytics` 后 `yolo` 不是命令 | 脚本目录不在 PATH           | 用 `python -m ultralytics ...`，或 `conda activate cv` 后重开终端 |
| `yolo train` 显存爆                        | 默认 imgsz=640、batch=16 | 显式 `imgsz=320 batch=4`；用 `yolov8n.pt`                     |
| `transformers` 报 `requires torch>=2.1`  | 版本太新                  | `pip install transformers==4.44.2`                        |
| HF 下载卡住 / 超时                            | 网络                    | 设 `HF_ENDPOINT=https://hf-mirror.com`                     |
| `DetrImageProcessor` 报参数不兼容             | transformers 版本差异     | 用 `processor(images=..., return_tensors="pt")`，别用旧参数名     |
| C 盘爆                                    | HF 缓存默认在 C 盘          | `set HF_HOME=D:\Research\hf_cache`                        |

### E.5 Git 类

| 现象                               | 根因              | 解法                                               |
| -------------------------------- | --------------- | ------------------------------------------------ |
| `git push` 要求账号密码                | 用了 HTTPS        | 配 SSH key，或装 GitHub CLI 登录                       |
| 提交了 `runs/` / `checkpoints/` 大文件 | `.gitignore` 没写 | 补 `.gitignore`；已提交的用 `git rm --cached` 移除        |
| `git status` 一堆 `??`             | 新文件未 add        | `git add <文件>`（**别用 `git add .` 一把梭**）           |
| 改错了想回退（未 commit）                 | —               | `git restore <文件>`                               |
| 改错了想回退（已 commit 未 push）          | —               | `git reset --soft HEAD~1`                        |
| 改错了想回退（已 push）                   | —               | `git revert <commit>`（**不要 `reset --hard` 后强推**） |
